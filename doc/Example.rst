Examples
========

Download and unzip ZoomX package or clone the source repository to $ZOOMXPKG.
ZoomX are most versatile if used from Python and R scripts directly.
To easy the initial learning, we also include a BASH script zoomxRun.
The script stages common analysis tasks with easily editable configure files. 

An example ZoomX germline analysis
--------------------------------------------------
To run this example, run the 'germline3.run' script in the 'test' subdir.
Full test data set is required, which can be downloaded at: 
`zoomx.test.full.tgz: <https://s3-us-west-2.amazonaws.com/lixiabucket/zoomx.test.full.tgz>`__

$ZOOMXPKG/test/germline3.cfg

  .. code:: bash

    #!/bin/bash
    #if zoomx python entry-points (parse10x, gridScan, refineBreak) 
    #and utility scripts are not in your PATH
    #ZOOMXPKG has to be set here 
    ZOOMXPKG=$HOME/setup/zoomx                #where the zoomx package is located
    ZOOMXPATH=$ZOOMXPKG/zoomx                 #where the python libs of zoomx are located
    SCRIPTPATH=$ZOOMXPKG/scripts              #where the uitlity scripts zoomx are located
    PATH=$SCRIPTPATH:$PATH                    #add script path to PATH
    mydate=$(LC_ALL=en_US.utf8 date +%Y%b%d)  #get today's date
    ref=human_g1k_v37.ucsc.fasta              #prefix to the grid file, the acutal ucsc reference fasta is not required
    grid=$ref.bed.w10Ks5K                     #scan grid file, here is a bed file of 10 Kbp half-overlap sliding windows
    covGrid=$ref.bed.w100s100                 #coverage grid file, here is a bed file of 100 bp non-overlap sliding windows
    outputPf=.                                #output dir
    distSize=200000                           #min base pair distance between breakpoints to qualify as distal junctions
    cisSize=50000                             #min base pair distance between breakpoints to qualify as mid-range junctions
    casePf=.                                  #input dir of case bam file
    caseBam=NA12878.wg12.chr22-22M-24M.bam    #name of case bam file, $caseBam.bai has to be in place
    caseExp=45                                #minimum expected allele frequency in case
    caseMax=1000                              #maximum expected number of junctions in case
    caseCovFile=$outputPf/$caseBam.cov100     #coverage file, $covGrid plus coverage col, generated by ZoomX in caseCovScan 
    isUCSC="--isUCSC"                         #turn on --isUCSC if in UCSC format, i.e. seqname is chrX not X
    maxPlot=100                               #maximum number of plots
    
    #following varialbes/filenames supposedly defined as in this configure file
    
    #Essential Input Files
    #$casePf/$caseBam                         #full path to the case bam file
    #$casePf/$caseBam.bai                     #full path to the case bam index file
    #$grid                                    #full path to the scan grid file
    #$covGrid                                 #full path to the coverage grid file
    #NOTE: $grid for 10 Kbp resolution and $covGrid for 100 bp resolution for hg37 in both UCSC and 1KG format are provided within this test folder; you can copy and use them as defaults.
    
    #Essential Output Files
    #$outputPf/$caseBam.tra.E$caseExp.refined #identified junction sites represeting inter/trans chromosome (trans) events
    #$outputPf/$caseBam.dist.E$caseExp.refined #identified junction sites represeting intra-chromosome distal (dis) events
    #$outputPf/$caseBam.cis.E$caseExp.refined #identified junction sites represeting intra-chromosome mid-range (cis) events
    #*.merged files are essentially *.refined files without short read pairs annotated
    #$X.refined.Plot-$i/ #supporting molecule plot and breakpoint information for $i-th event as in junction file "$X.refined"
    
    #Peripheral/Midway Outputs
    #$outputPf/$caseBam.cov100                #coverage file, $covGrid plus coverage col, generated by ZoomX in caseCovScan
    #$outputPf/$caseBam.multiFragBar.bed.a0   #bed file of inferred single molecule file, see FAQ of wiki for details
    #$outputPf/$caseBam.multiFragBar.bed.a0.clean   #single molecule file after cleaning by coverage
    #$outputPf/$caseBam.gridScan.cfg.json     #json file of informative statistics from linked-read sequencing data
    #$outputPf/$caseBam.IM|RR|FF.bedpe        #BEDPE file recording abnormal +-/-+, ++, and -- short read pairs
    #$outputPf/$caseBam.jct.bedpe.tra|dis|cis #BEDPE file recording candidate juctions for trans, distal and cis events
    
    #Log files
    #*log.*.$mydate                           #log files of standard outs from various stage, std err is not logged
    #*cfg.*.json.$mydate                      #log files in json format of actual ZoomX command lines ran

    #!/bin/bash
    if [[ -z $1 ]]; then
      cfgfile="germline3.cfg"

    source $cfgfile &&

    echo "$cfgfile.caseParse.json.$mydate" &&
    zoomxRun caseScan $cfgfile >$cfgfile.caseScan.json.$mydate &&
    echo "$cfgfile.caseScan.json.$mydate" &&
    zoomxRun caseDistRef $cfgfile >$cfgfile.caseDistRef.json.$mydate &&
    echo "$cfgfile.caseDistRef.json.$mydate" &&
    zoomxRun caseTransRef $cfgfile >$cfgfile.caseTransRef.json.$mydate &&
    echo "$cfgfile.caseTransRef.json.$mydate" &&
    zoomxRun caseCisRef $cfgfile >$cfgfile.caseCisRef.json.$mydate &&
    echo "$cfgfile.caseCisRef.json.$mydate" &&
    zoomxRun caseDistPlot $cfgfile >$cfgfile.caseDistPlot.json.$mydate &&
    echo "$cfgfile.caseDistPlot.json.$mydate" &&
    zoomxRun caseTransPlot $cfgfile >$cfgfile.caseTransPlot.json.$mydate &&
    echo "$cfgfile.caseTransPlot.json.$mydate" &&
    zoomxRun caseCisPlot $cfgfile >$cfgfile.caseCisPlot.json.$mydate &&
    echo "$cfgfile.caseCisPlot.json.$mydate"
