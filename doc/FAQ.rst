Usage Related

1-2. Q: How to generate or accelerate generation of $bamFile.cov100 file
-------------------------------------------------------------------------------------------------------------------------------------
  A: $bamFile.cov100 file is a 100 bp sliding window base coverage file generated by ZoomX (using samtools bedcov) at the caseCov or controlCov stage. It is crucial when the input data are noisy, in particular having coverage spikes representing sequencing/alignemnt errors. The file can be provided by user using faster tools such as sentineon using commands like following:

  .. code:: bash

    #!/bin/bash
    indir=$1
    bam=$2
    ref=$3 #HG19, HG38, HG38X or HG37
    nproc=$4
    win=$ref.bed.w99s100.sentieon
    tmpdir="/tmp/$bam"
    cmd0="mkdir $tmpdir || true"
    echo $cmd0
    cmd1="sentieon driver --temp_dir $tmpdir -t $nproc --interval $win --reference $ref --input $indir/$bam --algo CoverageMetrics $bam.sentieon"
    #NOTE: output file prefix does not allow any dir!
    echo nice time $cmd1
    cmd2="cat $bam.sentieon.sample_interval_summary | cut -f 1,2 | tr ':-' '\t' >$bam.cov100"
    echo nice time $cmd2

1-2. Q: How to understand $bamFile.multiFragBar.bed.aX file
-------------------------------------------------------------------------------------------------------------------------------------
  A: the file is generated by parse10x to save linked read single molecules. The molecules are inferred with culstering neighbor read pairs (distance<X) with the same barcode or by the 10X Genomics LongRanger (if X==0). The file is in tab delimited BED format and the columns are defined as following:

  .. code:: bash

    #CHR START END MOL_BAR_ID MOL_SIZE MOL_LENGTH COBAR_MOL MOL_ID MOL_HP MOL_PS MOL_BAR
    16  23284982  23325661  166332  14  40679 33  33953936  2 22713161 AGTCATGAGGCCTCCA-1
    #MOL_BAR_ID: internal barcode index of the molecule's barcode
    #MOL_SIZE: number of linked read pairs of the molecule
    #MOL_LENGTH: length of the molecule as inferred from position difference between first and last linked read pairs
    #COBAR_MOL: how many molecules sharing the same barcode
    #MOL_ID: molecule's id (LongRanger's molecule id if X==0)
    #MOL_HP: molecule's haplotype (LongRanger's molecule id if X==0)
    #MOL_PS: molecule's phaseblock id (LongRanger's molecule phase block id if X==0)
    #MOL_BAR: molecule's barcode (BX field in $bamFile)

Installation Related
====================

2-1. Q: Where to find the executables of ZoomX and add them to $PATH
-------------------------------------------------------------------------------------------------------------------------------------

  A: after successful installation of ZoomX, scritps are installed as console_scripts through entry points (Python) or installed as scripts (R and Bash). Both are automatically added to $PATH (of your virtual environment). A list of detailed locations are here:

  .. code:: bash

     #parse10x: directly available through entry_point
     #gridScan: directly available through entry_point
     #refineBreak: directly available through entry_point
     #plotStats.R: available through scripts
     #plotMolecule.R: available through scripts
     #bedpe2loupe.sh: available through scripts
     #getMolecule.sh: available through scripts
     #all other scripts: available through scripts though they are not supported
  
  The package can also work without installation as long as dependencies are satsified. To run withough installation, you will need to set $ZOOMXPATH

  .. code:: bash

     ZOOMXPATH=$HOME/setup/zoomx/zoomx/  #if your zoomx is cloned or unzipped to $HOME/setup/zoomx
     PYTHONPATH=$ZOOMXPATH python -m parse10x -h  #parse10x: directly available through entry_point
     PYTHONPATH=$ZOOMXPATH python -m gridscan -h  #gridScan: directly available through entry_point
     PYTHONPATH=$ZOOMXPATH python -m refineBreak -h #refineBreak: directly available through entry_point
     $ZOOMXPATH/../scripts/plotStats.R -h #plotStats.R: available through ../scripts/
     $ZOOMXPATH/../scripts/plotMolecule.R -h #plotMolecule.R: available through ../scripts/
     $ZOOMXPATH/../scripts/bedpe2loupe.sh #bedpe2loupe.sh: available through ../scripts/
     $ZOOMXPATH/../scripts/getMolecule.sh #getMolecule.sh: available through ../scripts/
     #all other scripts: available through ../scripts/ though they are not supported

2-3. Q: "csamtools.c" not found error when install pysam

  A: To install pysam, the samtools api has also to be able to compile on your system with dafault setting. 
  If you see above error in that process, this is because of libcurse is required for build samtools but often missing in Linux distros.
  Install libcurse and retry.
